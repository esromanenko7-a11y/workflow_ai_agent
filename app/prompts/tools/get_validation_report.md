Получает результаты автоматических проверок пакета данных по его идентификатору package_id.

Используй этот инструмент, когда пользователь спрашивает:
- прошёл ли конкретный пакет проверку;
- какие ошибки или предупреждения есть в пакете;
- можно ли передавать пакет дальше;
- что не так с пакетом по его ID.

Не используй этот инструмент, если пользователь задаёт общий вопрос без конкретного package_id, например:
- "что такое пакет данных?";
- "как лучше валидировать данные?";
- "какие бывают статусы проверок?".

В таких случаях отвечай обычным текстом без вызова инструмента.
