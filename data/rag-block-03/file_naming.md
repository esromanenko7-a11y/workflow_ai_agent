# Наименование файлов

Код проверки: `FILE_NAMING`
Категория: Проверка структуры пакета
Критичность: ERROR

## Описание проверки

Проверяем, что имя файла соответствует одному из утверждённых шаблонов, дата в имени файла имеет требуемый формат и корректное значение. В качестве разделителя между секциями используется двойное подчёркивание.

Шаблон наименования архива:
[наименование_реплики]_[YYYYMMDDHHMISS]_[кто_угодно].расширение

Шаблон наименования файла внутри архива:
[наименование_схемы/default]_[наименование_таблицы]_[YYYYMMDDHHMISS]_[кто_угодно].расширение

Шаблон наименования внешнего файла, если данные передаются без архива:
[наименование_реплики]_[наименование_схемы/default]_[наименование_таблицы]_[YYYYMMDDHHMISS]_[кто_угодно].расширение.

## Цель

Проверить соответствие имён архивов и файлов утверждённым шаблонам.

## Требования

- Имя архива должно соответствовать утверждённому шаблону.
- Имя файла внутри архива должно соответствовать утверждённому шаблону.
- Имя внешнего файла должно соответствовать утверждённому шаблону.
- Дата в имени файла должна иметь формат YYYYMMDDHHMISS.
- Дата в имени файла должна иметь корректное значение.
- Между секциями имени используется двойное подчёркивание.

## Примечания

- Точные регулярные выражения на фотографии читаются не полностью.
