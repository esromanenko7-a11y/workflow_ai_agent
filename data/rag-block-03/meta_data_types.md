# Тип данных

Код проверки: `META_DATA_TYPES`
Категория: Проверка meta-файла
Критичность: ERROR

## Описание проверки

Проверяем по meta-файлу, что типы данных — все те, которые система ожидает получать от источника.

## Цель

Проверить допустимость типов данных, описанных в meta-файле.

## Требования

- Типы данных в meta-файле должны соответствовать типам, ожидаемым от источника.
