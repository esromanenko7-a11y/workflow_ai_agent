# Проверка разархивирования

Код проверки: `PACKAGE_UNPACKING`
Категория: Проверка структуры пакета
Критичность: FATAL

## Описание проверки

Проверяем, что разархивирование происходит без ошибок.

## Цель

Проверить возможность успешно разархивировать пакет.

## Требования

- Архив должен разархивироваться без ошибок.

## Примечания

- Ошибка имеет уровень FATAL.
