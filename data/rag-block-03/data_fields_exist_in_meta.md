# Сверяем, что все указанные поля в meta-файле совпадают с полями в data-файле: Data vs Meta

Код проверки: `DATA_FIELDS_EXIST_IN_META`
Категория: Проверка data-файлов
Критичность: ERROR

## Описание проверки

Для каждой пары meta-файл и data-файл выполняем сверку атрибутивного состава. Атрибутивный состав, указанный в meta-файле, должен совпадать с атрибутивным составом data-файла по наличию полей.

## Цель

Проверить наличие в meta-файле описания всех полей data-файла.

## Требования

- Все поля data-файла должны быть описаны в meta-файле.

## Примечания

- Направление сверки: Data vs Meta.
