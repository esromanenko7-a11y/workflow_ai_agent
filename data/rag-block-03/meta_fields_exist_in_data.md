# Сверяем, что все указанные поля в meta-файле совпадают с полями в data-файле: Meta vs Data

Код проверки: `META_FIELDS_EXIST_IN_DATA`
Категория: Проверка data-файлов
Критичность: ERROR

## Описание проверки

Для каждой пары meta-файл и data-файл выполняем сверку атрибутивного состава. Атрибутивный состав, указанный в meta-файле, должен совпадать с атрибутивным составом data-файла по наличию полей.

## Цель

Проверить наличие в data-файле всех полей, описанных в meta-файле.

## Требования

- Все поля из meta-файла должны присутствовать в data-файле.

## Примечания

- Направление сверки: Meta vs Data.
