# Проверка на квотирование

Код проверки: `DATA_QUOTING`
Категория: Проверка data-файлов
Критичность: ERROR

## Описание проверки

Считываем первые 20 ГБ. Проверяем, что поля типа, отличного от string, не обрамляются кавычками.

## Цель

Проверить корректность использования кавычек для значений разных типов.

## Требования

- Поля типов, отличных от string, не должны обрамляться кавычками.

## Примечания

- Для проверки считываются первые 20 ГБ файла.
- Уровень критичности необходимо дополнительно сверить с исходной документацией.
